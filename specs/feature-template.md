# Feature Spec: Bookstore Website

## Title
Bookstore Website

## Application resource name
BookstoreApp

## Problem statement
We need a website that performs typical bookstore activities, allowing customers to browse and search inventory, and employees to manage book records.

## Goal
Deliver a web application that provides key bookstore functions for both customers (browsing and searching) and employees (full CRUD inventory management).

## Non-goals
- There is no purchase or checkout function needed at this time.
- User authentication and authorization are not in scope.
- Payment processing is not in scope.

## User stories
- As a customer
  - I want to be able to browse all books
  - So that I can find books in inventory

- As a customer
  - I want to be able to search for books
  - So that I can find the specific author or book title I'm looking for

- As an employee
  - I want to be able to add and remove books
  - So that I can manage inventory

- As an employee
  - I want to be able to edit an existing book's information
  - So that I can manage inventory
